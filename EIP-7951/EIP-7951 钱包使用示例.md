# EIP-7951 钱包使用示例：从助记词到 Face ID


## 实际案例：Obvious Wallet 和 Clave

根据实际项目，**Obvious Wallet** 和 **Clave** 等钱包已集成了 secp256r1 签名验证功能，使用户能够利用设备的安全环境（如手机的安全芯片）进行交易签名。

## 完整使用流程示例

### 场景：用户使用 iPhone 发送 ETH

#### 传统方式（secp256k1）的痛点

```
1. 用户打开钱包 App
2. 输入密码解锁钱包
3. 点击"发送 ETH"
4. 输入接收地址和金额
5. 再次输入密码确认
6. 等待交易确认
7. 如果忘记密码，需要输入助记词恢复

问题：
- ❌ 需要记住密码
- ❌ 需要备份助记词
- ❌ 操作步骤多
- ❌ 容易出错
```

#### EIP-7951 方式（secp256r1）的体验

```
1. 用户打开钱包 App
2. 点击"发送 ETH"
3. 输入接收地址和金额
4. 系统提示："请使用 Face ID 确认"
5. 用户看向手机，Face ID 识别成功
6. 交易自动签名并提交
7. 完成！

优势：
- ✅ 无需密码
- ✅ 无需助记词
- ✅ 只需看一眼手机
- ✅ 操作简单快速
```

## 技术实现示例

### 1. 钱包初始化（首次使用）

```typescript
// 钱包 App 初始化流程
async function initializeWallet() {
    // 1. 检查设备是否支持生物识别
    const hasBiometric = await checkBiometricSupport();
    if (!hasBiometric) {
        throw new Error('设备不支持生物识别');
    }
    
    // 2. 使用设备安全芯片生成 secp256r1 密钥对
    const keyPair = await generateSecp256r1KeyPair();
    // 私钥存储在 Apple Secure Enclave / Android Keystore
    // 私钥永不离开设备
    
    // 3. 重要：secp256r1 和 secp256k1 的地址不兼容
    // secp256k1 地址：keccak256(公钥)[12:] - 用于传统 EOA
    // secp256r1 公钥：不能用于推导传统 EOA 地址（曲线不同）
    // 
    // 在 EIP-7951 + ERC-4337 场景下：
    // - 钱包地址是智能合约地址（通过 CREATE/CREATE2 部署时确定）
    // - 公钥存储在智能合约中，用于验证签名
    // - 地址的有效性不依赖于曲线类型
    
    // 4. 使用 CREATE2 部署智能合约钱包（确定性地址）
    const salt = generateSalt(); // 随机 salt 或用户选择的 salt
    const walletAddress = await calculateCreate2Address(
        factoryAddress,
        salt,
        abi.encodePacked(entryPoint, keyPair.publicKeyX, keyPair.publicKeyY)
    );
    
    // 5. 部署智能合约钱包，将公钥存储在合约中
    // 注意：部署需要发送交易，有以下两种方式：
    
    // 方式 A：使用 Paymaster 代付 Gas（推荐，新用户无需 ETH）
    const initCode = encodeInitCode(factoryAddress, salt, keyPair.publicKeyX, keyPair.publicKeyY);
    const deployUserOp: UserOperation = {
        sender: walletAddress,
        nonce: 0,
        initCode: initCode, // 包含部署代码
        callData: '0x',
        callGasLimit: '200000',
        verificationGasLimit: '100000',
        preVerificationGas: '50000',
        maxFeePerGas: ethers.utils.parseUnits('20', 'gwei').toString(),
        maxPriorityFeePerGas: ethers.utils.parseUnits('2', 'gwei').toString(),
        paymasterAndData: paymasterAddress, // Paymaster 代付部署 Gas
        signature: '0x' // 稍后填充
    };
    
    // 计算 Hash 并签名
    const deployHash = await entryPoint.getUserOpHash(deployUserOp);
    deployUserOp.signature = await signWithSecureEnclave(deployHash);
    
    // 发送到 Bundler
    // 实际执行流程：
    // 1. Bundler 调用 EntryPoint.handleOps()，Bundler 支付 Gas
    // 2. EntryPoint 验证签名（调用钱包的 validateUserOp，此时钱包还未部署）
    // 3. EntryPoint 执行 initCode，部署钱包合约
    // 4. Paymaster 转账给 EntryPoint 补偿 Bundler
    // 5. EntryPoint 补偿 Bundler
    const userOpHash = await sendToBundler(deployUserOp);
    await waitForUserOperation(userOpHash);
    
    // 方式 B：用户自己支付 Gas（需要用户账户有 ETH）
    // 注意：这需要用户先有一个 EOA 账户并充值 ETH
    // const deployTx = await factory.createWallet(salt, keyPair.publicKeyX, keyPair.publicKeyY, {
    //     value: 0,
    //     gasLimit: 500000
    // });
    // await deployTx.wait(); // 等待交易确认，用户支付 Gas
    
    console.log('钱包创建成功！');
    console.log('地址：', walletAddress);
    console.log('无需备份助记词，私钥安全存储在设备中');
    console.log('Gas 费用：', usePaymaster ? '由 Paymaster 代付' : '用户支付');
}
```

### 2. 发送交易（日常使用）

```typescript
// 发送 ETH 交易
async function sendETH(to: string, amount: string) {
    // 1. 构建 UserOperation
    const userOp = {
        sender: walletAddress,
        nonce: await getNonce(),
        callData: encodeTransfer(to, amount),
        // ... 其他字段
        paymasterAndData: paymasterAddress, // 使用 Paymaster 代付 Gas
        signature: '0x' // 稍后填充
    };
    
    // 2. 计算 UserOperation Hash
    const userOpHash = await entryPoint.getUserOpHash(userOp);
    
    // 3. 提示用户使用生物识别
    const biometricResult = await requestBiometricAuth('请使用 Face ID 确认交易');
    
    if (!biometricResult.success) {
        throw new Error('生物识别验证失败');
    }
    
    // 4. 设备安全芯片使用私钥签名（secp256r1）
    const signature = await signWithSecureEnclave(userOpHash);
    // 签名在安全芯片内部完成，私钥永不离开设备
    
    // 5. 填充签名
    userOp.signature = signature;
    
    // 6. 发送到 Bundler（实际执行流程）
    // Bundler 会：
    // a) 调用 EntryPoint.handleOps()，Bundler 支付 Gas
    // b) EntryPoint 验证签名（调用钱包的 validateUserOp）
    // c) EntryPoint 执行用户操作（调用钱包的 execute）
    // d) 如果有 Paymaster，Paymaster 转账给 EntryPoint 补偿 Bundler
    // e) EntryPoint 补偿 Bundler
    const txHash = await sendToBundler(userOp);
    
    // 7. 等待交易确认
    const receipt = await waitForTransaction(txHash);
    
    console.log('交易已提交！', txHash);
    console.log('无需输入密码，只需 Face ID 确认');
    console.log('Gas 费用：', userOp.paymasterAndData ? '由 Paymaster 代付' : '从钱包余额扣除');
}

// 发送到 Bundler 的完整实现
async function sendToBundler(userOp: UserOperation): Promise<string> {
    const bundlerUrl = 'https://bundler.example.com/rpc';
    
    const response = await fetch(bundlerUrl, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
            jsonrpc: '2.0',
            id: 1,
            method: 'eth_sendUserOperation',
            params: [userOp, entryPointAddress]
        })
    });
    
    const result = await response.json();
    
    if (result.error) {
        throw new Error(result.error.message);
    }
    
    // 返回 UserOperation Hash
    // 注意：这不是交易 Hash，而是 UserOperation 的 Hash
    // 实际交易由 Bundler 发送，交易 Hash 可以通过其他方式查询
    return result.result;
}
```

### 3. 智能合约钱包验证（链上）

```solidity
// 智能合约钱包的验证逻辑
contract BiometricWallet {
    address public immutable entryPoint;
    uint256 public publicKeyX; // 公钥 x 坐标
    uint256 public publicKeyY; // 公钥 y 坐标
    
    function validateUserOp(
        UserOperation calldata userOp,
        bytes32 userOpHash,
        uint256 missingAccountFunds
    ) external returns (uint256 validationData) {
        require(msg.sender == entryPoint, "Only entryPoint");
        
        // 从 signature 中提取 secp256r1 签名
        (uint256 r, uint256 s) = abi.decode(
            userOp.signature, 
            (uint256, uint256)
        );
        
        // 使用 EIP-7951 预编译验证签名
        bytes memory input = abi.encodePacked(
            userOpHash,  // 32 bytes: 消息哈希
            r,           // 32 bytes: 签名 r
            s,           // 32 bytes: 签名 s
            publicKeyX,  // 32 bytes: 公钥 x
            publicKeyY   // 32 bytes: 公钥 y
        );
        
        // 调用 EIP-7951 预编译（地址 0x100）
        (bool success, bytes memory result) = address(0x100).staticcall(input);
        require(success && result.length == 32, "Verification failed");
        
        uint256 verified = abi.decode(result, (uint256));
        require(verified == 1, "Invalid signature");
        
        return 0; // 验证成功
    }
}
```

## 用户体验对比

### 传统钱包（secp256k1）

```
用户操作步骤：
1. 打开钱包 → 2. 输入密码 → 3. 点击发送 → 4. 输入地址 → 5. 输入金额
```

```
用户操作步骤：
1. 打开钱包 → 2. 点击发送 → 3. 输入地址 → 4. 输入金额 
→ 5. Face ID 确认 → 6. 完成

总耗时：10-15 秒
需要记忆：无
安全风险：极低（硬件级保护）
```

## 完整代码示例

### iOS 端实现（Swift）

```swift
import LocalAuthentication
import CryptoKit

class BiometricWallet {
    // 使用 Secure Enclave 生成密钥
    func generateKeyPair() throws -> (publicKey: P256.Signing.PublicKey, privateKey: P256.Signing.PrivateKey) {
        let accessControl = SecAccessControlCreateWithFlags(
            kCFAllocatorDefault,
            kSecAttrAccessibleWhenUnlockedThisDeviceOnly,
            [.privateKeyUsage, .biometryAny],
            nil
        )!
        
        let privateKey = try P256.Signing.PrivateKey(
            accessControl: accessControl
        )
        
        return (privateKey.publicKey, privateKey)
    }
    
    // 使用 Face ID 签名
    func signWithBiometric(message: Data) async throws -> Data {
        let context = LAContext()
        var error: NSError?
        
        // 检查生物识别可用性
        guard context.canEvaluatePolicy(.deviceOwnerAuthenticationWithBiometrics, error: &error) else {
            throw WalletError.biometricNotAvailable
        }
        
        // 请求生物识别
        try await context.evaluatePolicy(
            .deviceOwnerAuthenticationWithBiometrics,
            localizedReason: "请使用 Face ID 确认交易"
        )
        
        // 使用 Secure Enclave 签名
        let signature = try privateKey.signature(for: message)
        return signature.rawRepresentation
    }
}
```

### Android 端实现（Kotlin）

```kotlin
import android.security.keystore.KeyGenParameterSpec
import java.security.KeyStore
import javax.crypto.KeyGenerator

class BiometricWallet {
    private val keyStore = KeyStore.getInstance("AndroidKeyStore")
    
    // 使用 Android Keystore 生成密钥
    fun generateKeyPair(): KeyPair {
        val keyGenerator = KeyGenerator.getInstance(
            KeyProperties.KEY_ALGORITHM_EC,
            "AndroidKeyStore"
        )
        
        val keyGenParameterSpec = KeyGenParameterSpec.Builder(
            "wallet_key",
            KeyProperties.PURPOSE_SIGN
        )
            .setDigests(KeyProperties.DIGEST_SHA256)
            .setAlgorithmParameterSpec(ECGenParameterSpec("secp256r1"))
            .setUserAuthenticationRequired(true)
            .setUserAuthenticationValidityDurationSeconds(-1)
            .build()
        
        keyGenerator.init(keyGenParameterSpec)
        keyGenerator.generateKey()
        
        val publicKey = keyStore.getCertificate("wallet_key").publicKey
        val privateKey = keyStore.getKey("wallet_key", null) as PrivateKey
        
        return KeyPair(publicKey, privateKey)
    }
    
    // 使用指纹签名
    suspend fun signWithBiometric(message: ByteArray): ByteArray {
        val biometricPrompt = BiometricPrompt(
            activity,
            executor,
            object : BiometricPrompt.AuthenticationCallback() {
                override fun onAuthenticationSucceeded(result: BiometricPrompt.AuthenticationResult) {
                    // 使用 Android Keystore 签名
                    val signature = Signature.getInstance("SHA256withECDSA")
                    signature.initSign(privateKey)
                    signature.update(message)
                    val signedData = signature.sign()
                }
            }
        )
        
        val promptInfo = BiometricPrompt.PromptInfo.Builder()
            .setTitle("确认交易")
            .setSubtitle("请使用指纹确认")
            .setNegativeButtonText("取消")
            .build()
        
        biometricPrompt.authenticate(promptInfo)
    }
}
```

## 关键优势总结

| 特性 | 传统钱包 | EIP-7951 钱包 |
|------|---------|--------------|
| **初始化** | 生成助记词，需要备份 | 设备自动生成，无需备份 |
| **登录方式** | 密码 | Face ID / Touch ID / 指纹 |
| **交易确认** | 输入密码 | 生物识别 |
| **私钥存储** | 软件存储（可被窃取） | 硬件安全芯片（不可导出） |
| **操作步骤** | 7-8 步 | 5-6 步 |
| **耗时** | 2-3 分钟 | 10-15 秒 |
| **安全级别** | 中等 | 硬件级 |
